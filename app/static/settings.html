📺 遥控器

电视设置

电视的局域网 IP：电视 → 设置 → 网络 → 查看，或用下面“发现电视”扫描。
默认 5555，改过 ADB 端口才需要改。
电视 → 设置 → 关于本机 → 状态信息里看，或路由器后台查。没有 MAC 也能遥控，只是开不了机。

发现电视

扫描本机所在网段的 ADB 端口（5555），列出响应的设备，点“填入”把 IP 写进上面。

怎么开 ADB（只做一次）

  1. 电视上：设置 → 关于本机 → 连点“版本号”7 下，提示“已进入开发者模式”。
  2. 回到设置 → 开发者选项（或“系统 → 开发者选项”）→ 打开“ADB 调试”。
  3. 回遥控器点“测试连接”：电视上会弹出“允许 USB 调试？”的框，点“允许”（可勾“始终允许这台计算机”），再点一次测试连接，应显示“已连接”。
  4. 如果测试一直显示“连接被拒”：确认 ADB 调试已开、电视和 NAS 在同一个网段、IP 没填错。

注意：小米电视如果没有开发者选项或开不了 ADB 调试，本应用无法使用（电视厂商锁死了这条路）。局域网唤醒只在电视待机不断电、且支持网络唤醒时有效；彻底断电关机后唤不醒。

账号密码

忘密码：删数据目录 config.json 里的 auth 段，重启应用恢复默认 admin/admin。
